# CORE Arona Desktop

Windows向け、ユーザー所有のMMDモデルをデスクトップ上に表示するローカルファーストのアバターホスト。

> Phase 1: PMX/PMD表示・透明ウィンドウ・ドラッグ移動・モデル差し替え。
> 音声、モーション、ウィンドウ着座、クリック透過、インストーラーは今後のPhaseで実装します。

## 必要なもの

- Windows 10/11
- Node.js 22.12以降（Node 24 LTSを推奨）、npm
- 正当に利用できる .pmx または .pmd モデルと、付属のテクスチャフォルダ

## 起動

1. このリポジトリをクローンする。
2. ターミナルで npm install を実行する。
3. npm start を実行する。起動時にViteで描画部分をビルドしてElectronを開きます。
4. 上部の「モデル選択」から .pmx / .pmd ファイルを選ぶ。
5. 上部の「CORE / ARONA」と書かれたバーをドラッグして、デスクトップ上の位置を変える。
6. × で終了する。

再起動時には最後に選択したモデルのパスをローカルのElectron userData/settings.jsonから復元します。
選択したモデルとテクスチャは、元のローカルフォルダから読み込みます。コピーやアップロードは行いません。

## テスト

npm test : モデルのファイルパスを安全に解決する処理の単体テスト。

## モデルの管理方針

モデル本体、テクスチャ、モーション、音声ライブラリ、ライセンスで制限された素材はGitに入れません。
リポジトリにはアプリのコードのみを保存し、各利用者が正当に入手したモデルを自分のPCで選ぶ方式です。
モデルの個人利用・加工・商用利用・アプリでの利用については素材ごとの規約に従ってください。
音声エンジン(VoiSona Talk等)も今後オプション連携とし、音源・製品本体を配布しません。

## Phase 1 の制約

- 最前面の透明ウィンドウを表示しますが、透明な領域もマウス操作を遮ります。クリック透過は未実装です。
- モデルごとの独特なテクスチャ形式やパス参照によっては、正常に表示されない場合があります。
- モーション・物理演算・リップシンクは未実装です。初期ポーズのみを表示します。
- Windows上での実機描画テストは別途必要です。依存パッケージのインストール後に確認してください。
- 現時点では開発者向けの npm start 起動であり、配布可能なインストーラーではありません。
