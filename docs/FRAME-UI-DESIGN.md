# FRAME UI セマンティックカラー規約

FRAMEのApple風ダークUIにおける操作意味と配色の統一規約。既存の濃紺の落ち着いた質感を重視し、鮮やかな不透明ブルーの面塗りを主要操作へ使わない。

| 種別 | 対象 | 通常状態 | 注意点 |
| --- | --- | --- | --- |
| ① 状態表示 | 接続・起動・処理・異常 | ダークグレーのパネル＋小さな点。正常は緑 `#30c76a`、処理中は青 `#2997ff`、異常は赤い丸の中に `!` | パネル全体を緑・赤にはしない。停止／未接続など正常な非稼働は中立の灰色 |
| ② アクション | 設定・起動・実行・保存 | 基本はグレー `#333336`。重要操作のみ `rgba(41,151,255,.16)` と淡い青い境界 | ホバーで少し明るく。設定画面への移動は通常グレー、ホバーで青みを加える |
| ③ ON/OFF | 自動起動・自動非表示・演出切替 | ON時は現行の濃紺 `#263a52`、OFFはグレー | ON/OFFの文字・`aria-pressed`でも区別。既存のON色を維持 |
| ④ 停止・終了 | 再生停止・終了・削除・ウィンドウ閉じる | 薄い赤背景＋赤い文字・赤い輪郭 | 単なるキャンセル／戻るはグレー。タイトルバーの×のみ半透明赤背景＋暗色 `#171719` の×。ホバーで赤を強調 |
| ⑤ 選択 | 音声・表情・モーション・タブ・切替方式 | 選択中は濃紺 `#25354a`＋青輪郭、未選択はグレー | 選択状態を輪郭・チェック・`aria-selected`等でも表現 |

## 共通ルール

- 無効操作は低コントラストで示し、クリック不可にする。
- キーボードのフォーカスは青輪郭で明示する。
- ホバーは既存コンポーネントより少し明るく。青／赤の用途を入れ替えない。
- 半透明のアクセントは活かしつつ、既存の `#263a52` のように透明感があるように見える濃紺は不透明のまま維持する。
- エラー判定は実際の失敗情報に紐づける。停止中・未接続を自動的にエラー扱いしない。
- 質感のために操作内容・操作意味を変えない。アクセシビリティを維持する。

## 実装箇所

- `electron/avatar-menu.css`：メインパネル・状態・切替・選択・右上の×
- `electron/avatar-menu.html` / `electron/avatar-menu.js`：各操作の分類と状態に応じた表示
- `electron/voice-settings.html` / `electron/voice-settings.js`：認証設定画面
- `src/style.css`：MMD未設定時の初期画面

参照：Projectの `DESIGN.md` / `tokens.json` / `variables.css`。配色規約はFRAME固有の意味づけとして適用する。
