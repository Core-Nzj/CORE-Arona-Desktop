# ADR-0003: FRAME視覚接続アダプターと一時画像セッション

- ステータス: **採用（Accepted）**
- 決定日: 2026-10-31
- 対象: 研究所専用のFRAME視覚プラグインとChatGPT等の外部受信先を接続する境界
- 実装状況: **設計のみ。接続アダプター・画像送信は未実装**
- 関連: [ADR-0002](0002-frame-core-plugin-architecture.md)、[視覚プラグイン試作](../plugins.md)、[Issue #4](https://github.com/Core-Nzj/CORE-Arona-Desktop/issues/4)

## 決定

**撮影（Vision）と送信（Connection）を独立させる。** FRAMEは、プラグインから受け取った画像を一時的にメモリで管理し、**利用者が対象と送信先を確認して明示的に許可した一枚だけ**を接続アダプターに渡す。自動保存・自動送信・継続監視は行わない。

接続方式は後から交換できる構造とし、ChatGPT通常Chatで使用できる方式が未確認であることを前提にする。MCP、Work、Codex、Business契約、有料AI APIのいずれもFRAME Coreの必須依存にしない。

```text
  ChatGPT通常Chat / 将来の対応クライアント
                   ↑ （対応可否は経路ごとに実証する）
           Connection Adapter
         （Browser / MCP / 将来の方式）
                   ↑ 明示的な送信許可後のみ
          Vision Session Broker
      （対象・宛先・有効期限・破棄を管理）
                   ↑ 撮影要求
         FRAME Plugin Host / API
                   ↑
     研究所専用 Vision Plugin（非公開）
                   ↑
               Windows
```

## 責務境界

| 部品 | 担当 | 禁止・制約 |
| --- | --- | --- |
| Vision Plugin | 指定されたHWND/PIDの撮影・PNGの返却 | ChatGPTと直接通信しない。ファイルへ保存しない |
| Plugin Host | 既存の許可ハッシュ照合・対象検証・撮影の実行 | 任意スクリプトの無条件ロード、無断撮影をしない |
| Vision Session Broker（新設） | 画像の短期保持、送信同意、期限・破棄、単発送信 | 送信先を勝手に選ばない。画像やタイトルをログ・永続設定へ出さない |
| Connection Adapter（新設） | 承認済みのPNGを特定の受信先が扱える形式へ変換・転送 | 撮影APIやプラグイン実装を直接操作しない |
| FRAME Core | 許可UIと既存の読み上げ・アバターを維持 | 視覚機能や通信先の存在を起動条件にしない |

この段階で実装済みなのは、ウィンドウ一覧・撮影・メモリ上のプレビュー・破棄まで。BrokerとAdapterは未実装。既存の `FramePluginHost.state().capture.dataUrl` は試作用の画像表現であり、将来の外部公開APIと同一視しない。

## 権限を分ける

権限は次の三層を混同しない。

1. **プラグイン実行の許可**: 導入したローカルスクリプトをFRAMEで動作させてよいか（既存）。
2. **特定ウィンドウの撮影指示**: どの対象を、いつ撮るか（既存の手動撮影）。外部要求だけでは実行しない。
3. **撮影画像の送信許可**: どの画像を、どのChatGPT会話・受信先へ渡すか（新設）。プラグイン実行許可や撮影指示から自動的に付与されない。

将来「アロナ、VSCodeを見て」と外部側から要求が来ても、初期設定ではFRAME上で要求元・対象・送信先を提示し、利用者の承認後に撮影・転送する。現在の撮影済み画像を共有する場合も、送信先を示して別途承認する。権限確認を省略する常時監視モードは設けない。

## 一時画像セッション（v1契約案）

- セッションは `requestId`（推測困難な乱数ID）、`source`、`target`（pluginId / windowId / PID）、`destinationId`、`capturedAt`、`expiresAt`、`status`、PNG本体を持つ。
- `status` は `pending -> captured -> approved -> delivered`、または任意段階から `revoked / expired / failed`。承認前の画像はアダプターへ渡さない。
- 同時セッションは原則1件。画像は原則1枚、上限は既存プラグインのPNG 8MiBを超えない。プロトコル変更はバージョン管理する。
- 許可は**画像1枚・送信先1か所・送信1回**に限定。新たな再撮影には再承認が必要。
- 撮影後60秒を過ぎたら未送信画像と許可を自動失効する（実装時に実測で調整可）。明示消去、プラグイン無効化、パネル終了、アダプター切断時は速やかに失効させる。
- PNG本体はRAM中のみで処理する。自動保存・履歴DB・一時PNGファイル・画像内容を含むログは作成しない。ただしOSのページング・クラッシュダンプ等による物理ディスク書き込みは保証の対象外。
- 受信先に必要ないウィンドウタイトル・PID・ローカルパスは送らない。画像に機密情報が映り込む可能性は利用者へ明示する。

※このセッション契約は**これからの実装目標**であり、現行のプレビュー保持が60秒で消えるという意味ではない。

## アダプターの内部契約（v1案）

- `getCapabilities()`: その接続方式が画像の送信・受信を扱えるか、許可が必要かを報告する。
- `deliver({ requestId, destinationId, mimeType: "image/png", imageBytes })`: Brokerが認可した画像だけを受け取る。内部ではBuffer等のバイト列を使い、外部プロトコルへのBase64変換はアダプター境界で行う。
- `cancel(requestId)` / `disconnect()`: 承認や転送を取り消し、一時参照を解放する。
- 成功は「相手側が受信した」と確認できた場合に限って表示する。通信開始だけで「ChatGPTが見た」とは表示しない。
- 接続不可・送信失敗なら失敗を明示し、**代替の外部送信を自動実行しない**。画像内容、認証トークンをエラー表示やログへ出さない。

接続アダプターは画像の意味理解を実装しない。解釈はChatGPT等の受信側に任せる。

## 接続方式の優先順位と未検証点

1. **内部インターフェース + ダミー受信先**: 画像の認可・受け渡し・失効・破棄をローカルのみで確認。ネットワーク通信不要。
2. **通常Chat向け候補の検証**: 既存のブラウザ拡張との連携も候補。ただし、ChatGPT画面への画像添付/認識が現在のブラウザで成立するかは**未実証**。実現可能性が確認できるまで採用しない。
3. **MCPアダプター（任意）**: Inspector等での試験を独立して行う。Issue #4ではMCPのpingがInspectorとWorkで成功、通常Chatでは未成功。画像のMCPツール結果が通常Chatへ届くことは**未確認**。
4. 受信先にリモートMCPが必要な場合、公開するネットワーク経路・アカウント/プラン・審査・トンネルの安全性と費用は別途検証する。ローカルMCPを作るだけではChatGPTから自動的に使えるようにならない。

接続方式の選定は技術実証後。これらの候補をFRAMEの必須依存にしない。

## 接続境界のセキュリティ条件

- 将来ローカルHTTP等を使う場合は、標準でloopbackのみにバインドする。LANやインターネットへ公開しない。
- 起動ごとに生成した一時認証情報で送信元を認証し、Origin・宛先・対象を検証する。トークンをURL、ログ、Git、設定ファイルへ書かない。
- 不明な要求元は拒否。要求受信と画像送信は別動作であり、外部コマンドだけで画面撮影を始めない。
- 時間制限、画像サイズ上限、1件ずつの処理、重複要求IDの拒否、セッション取消を設ける。
- FRAMEの公開リポジトリには研究所用撮影スクリプト・秘密鍵・プライベート認証情報を収録しない。

## 実装の分割と完了条件

1. **第1工程**: BrokerとダミーAdapterを独立モジュールとして追加。既存の撮影UI・TTS・MMDに影響させない。
2. **第2工程**: 送信許可UIと一回限りの共有操作を追加。送信先/画像/拒否を確認できること。
3. **第3工程**: 選んだChatGPT接続経路を小さく実証した後、その方式専用Adapterを追加。
4. **検証**: 未許可では画像が渡らない、許可後は一回のみ、期限切れ・閉鎖・権限取消で失効、失敗時の外部転送なし、PNGファイル生成なし、通常の読み上げ/アバター機能が影響を受けない、を重点テストする。

## 対象外

画像認識モデル/OCR、定期撮影、カメラ、常時画面監視、PC操作の自動化、画像のローカル保存機能、ChatGPT APIの有料呼び出しを本ADRのスコープに含めない。
