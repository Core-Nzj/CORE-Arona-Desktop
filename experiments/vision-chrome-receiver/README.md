# FRAME / Chrome Vision Receiver（研究用）

この拡張はFRAMEのRAM上で撮影・承認したPNGを、同じPCのChromeへ一度だけ渡す通信経路の検証用です。画像をChatGPTへ添付する実装ではありません。

## 導入
1. Visionブランチで `git pull` → `npm start`。
2. Chromeで `chrome://extensions/` を開き、「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」から、この `experiments/vision-chrome-receiver` フォルダを選択。
4. FRAME「拡張」でウィンドウを撮影。「CHROME BRIDGE / EXPERIMENT」で内容を確認し、チェックを入れて「Chrome受信待機を開始」。
5. 「認証コードをコピー」を押す。FRAMEの設定パネルを閉じずにChromeの拡張アイコンを開き、コードを貼り付け「FRAMEから画像を1回受け取る」を押す。
6. 画像のプレビューと「受信成功」が表示されれば、ブラウザまでの橋渡し成功。同じコードで2回目は受信できません。

FRAMEパネルはChrome受信待機中だけフォーカスアウトで自動的に閉じず、× / Esc /「待機を取消」では通常どおり取消します。60秒後も自動取消。受信後は従来のフォーカスアウト動作に戻ります。

## セキュリティ・制約
- FRAMEのHTTPサーバーは `127.0.0.1:32780` のみで待ち受け、受信開始時に起動。128bit以上（実装は256bit）認証コードが必要。
- 認証コードはURL・設定ファイル・ログへ保存しない。ユーザー操作でコードだけをWindowsクリップボードへコピーする（画像はコピーしない）。
- 受信画像はメモリ上で処理し、ファイル保存・ChatGPT等へのネットワーク送信・外部画像API呼び出しはしない。通常の画像履歴やパスワード管理機能にも保存しない。
- 研究用のChrome拡張を追加する実験であり、既存の読み上げChrome拡張とは別物です。
- 新しいFRAME起動に失敗した場合も音声/MMD機能への影響を避け、Chrome接続機能だけエラーにする。
- ブラウザへの受信を確認できても、ChatGPT通常Chatに画像が添付・認識されることは未確認。ここは次の検証工程。
